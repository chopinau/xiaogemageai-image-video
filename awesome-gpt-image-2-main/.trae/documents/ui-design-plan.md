# UI 设计方案 — 小马AI 风格改造 + 文生图功能

## 一、需求分析

### 1.1 现状问题
- 当前界面为传统的左右两栏布局（参数面板 + 结果面板），类似传统工具站
- 缺少最基础的「文生图」功能（纯提示词生成，不带参考图）
- 导航结构较平，缺少对话式/流式交互体验

### 1.2 目标
1. **界面风格改造**：参考小马AI的对话式界面，打造沉浸式 AI 创作体验
2. **新增文生图功能**：支持纯提示词生成图片，可选上传参考图

### 3.2 文生图功能 — 详细设计

**功能名称**: 文生图 (Text-to-Image)
**入口**: 左侧 Sidebar → 图片生成 → 选择具体模型
**路由**: `/image-gen` (新增)

#### 交互流程

```
1. 用户选择 "图片生成" 分类
2. 默认选中第一个可用模型 (如 GPT Image 2)
3. 用户在底部输入框输入提示词
4. 可选：点击 📎 上传参考图 (开启 image-to-image 模式)
5. 点击发送或按 Enter
6. 系统显示 "生成中..." 占位卡片
7. 生成完成后，图片卡片出现在对话流中
8. 用户可对单张图片：下载、收藏、重新生成、编辑、放大
```

#### 图片结果卡片设计

```
┌────────────────────────────────┐
│  [生成的图片]                    │
│                                │
├────────────────────────────────┤
│  🎨 GPT Image 2  ·  1024x1024  │
│  "一只穿着宇航服的猫咪..."       │
├────────────────────────────────┤
│  ⬇️  💾  🔄  ✏️  🔍            │
│ 下载 收藏 重绘 编辑 放大        │
└────────────────────────────────┘
```

#### 参考图模式

当用户上传参考图后，输入区显示:
```
┌─────────────────────────────────────────┐
│ [参考图缩略图] ×  │  基于参考图生成...    │
└─────────────────────────────────────────┘
```
- 参考图自动附带参数 `image_url` 发送到后端
- 支持 Flux Kontext、SeedEdit 等图生图模型

## 五、状态管理设计

### 5.1 对话状态

```javascript
// 单条消息
interface ChatMessage {
  id: string;
  role: 'user' | 'assistant' | 'system';
  type: 'text' | 'image' | 'video' | 'error';
  content: string;
  attachments?: Attachment[];  // 用户上传的参考图
  results?: GenerationResult[]; // AI 生成的结果
  model?: string;
  params?: GenerationParams;
  timestamp: number;
  status: 'pending' | 'generating' | 'completed' | 'failed';
}

// 生成结果
interface GenerationResult {
  id: string;
  type: 'image' | 'video';
  url: string;
  thumbnail?: string;
  width?: number;
  height?: number;
  prompt?: string;
}
```

### 5.2 全局状态

```javascript
interface AppState {
  currentCategory: 'chat' | 'image' | 'video' | 'psd';
  currentModel: string;
  messages: ChatMessage[];
  isGenerating: boolean;
  sidebarCollapsed: boolean;
}
```

## 七、实施步骤

### Step 1: 基础框架改造
1. 改造 `Sidebar` → `ModelSidebar`，支持模型分类展示
2. 新建 `CreativeHub.jsx` 页面框架（对话流 + 输入区布局）
3. 调整 `App.jsx` 路由，首页指向 `CreativeHub`

### Step 2: 对话流组件
1. 新建 `ChatStream.jsx` + `ChatMessage.jsx`
2. 实现消息渲染（文本、图片、视频、加载中）
3. 实现滚动到底部、新消息动画

### Step 3: 输入区组件
1. 新建 `InputBar.jsx`
2. 实现提示词输入框（自动高度、@和/快捷触发）
3. 实现参考图上传（紧凑模式）
4. 实现参数快捷栏（模型、数量、尺寸）

### Step 4: 结果卡片
1. 新建 `ImageResultCard.jsx`
2. 实现图片展示、操作按钮（下载/收藏/重绘/编辑/放大）
3. 新建 `GenerationSkeleton.jsx` 加载占位

### Step 5: 文生图功能集成
1. 在 `imageGenerator.js` 中确认 `generate()` 方法支持纯 prompt（不带参考图）
2. 在 `InputBar` 中集成调用逻辑
3. 处理生成结果，推送到 `ChatStream`

### Step 6: 图生图功能（参考图模式）
1. 当用户上传参考图时，调用 `imageGenerator.edit()` 或 `generate()` 带 image 参数
2. 在消息中展示参考图和生成结果的关联

### Step 7: 状态管理与历史
1. 使用 `useAI` Hook 扩展，支持对话式消息管理
2. 历史记录按对话线程存储

### Step 8: 样式统一
1. 确保所有新组件使用现有 `shared.css` 变量和样式模式
2. 保持深色主题、渐变按钮、毛玻璃效果等视觉一致性

## 八、视觉规范

### 8.1 色彩（保持现有）
- 背景: `#060914` → `#0b1020`
- 卡片背景: `rgba(9, 15, 32, 0.68)` + `backdrop-filter: blur(12px)`
- 主色: `#42e6ff` (青)
- 辅色: `#78ffb9` (绿)、`#f9ff72` (黄)
- 强调: `#ff4aa6` (粉)
- 文字: `#eef5ff` (主)、`#aebcd0` (次)、`#73859f` (弱)

### 8.2 布局尺寸
- 左侧 Sidebar: `260px`
- 主内容区: `calc(100% - 260px)`
- 底部输入区: 最小 `120px`，最大 `240px`
- 对话流最大宽度: `900px`，居中

### 8.3 动画
- 消息进入: `fadeIn + translateY(10px)`，200ms
- 生成中: 骨架屏 shimmer 动画
- 图片加载: 模糊到清晰的 `transition`
- 发送按钮: 点击涟漪效果

## 十、风险与备选

1. **复杂度**: 对话式 UI 比表单复杂，建议先实现基础版本再迭代
2. **性能**: 大量图片消息可能导致内存问题，需实现虚拟滚动或分页加载
3. **移动端**: 左侧 Sidebar 在移动端需折叠为抽屉式
4. **向后兼容**: 原 `MainImageGen` 等页面可保留在 `/legacy` 路径或完全替换
