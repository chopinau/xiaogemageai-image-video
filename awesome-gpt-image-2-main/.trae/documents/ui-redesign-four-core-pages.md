# UI 修改与四大核心功能页面实施计划

## 一、项目现状分析

**当前架构**：单文件 React 应用（`main.jsx` 762 行），无路由系统，所有组件和逻辑集中在一个文件中。

**已有基础设施**：
- `src/config/models.js` — AI 模型配置（图像/视频/文本模型）
- `src/config/api.js` — API 端点配置
- `src/services/` — 图像/视频/文本生成服务 + 历史管理
- `src/hooks/useAI.js` — React Context + Hooks（AIProvider, useAI, useHistory, useUsageStats）
- `src/styles.css` — 暗色主题玻璃拟态风格

**核心约束**：保留原有 IMAGE2 提示词模板画廊全部功能，仅增加功能。

## 二、架构改造方案

### 2.1 引入路由系统
- 安装 `react-router-dom` 依赖
- 采用 HashRouter（兼容静态部署，无需服务端配置）
- 路由表：
  - `/` → 主图生成 2.0（平台核心首页）
  - `/detail-studio` → 一键生图工作室（详情图生成）
  - `/retouch-studio` → 图片精修工作室
  - `/video-gen` → 视频生成
  - `/gallery` → 原有 IMAGE2 提示词画廊（保留完整功能）

1. 安装 `react-router-dom`

3. 改造 `src/main.jsx`，挂载 BrowserRouter + AIProvider

   - 电商宽高比预设：1:1, 3:4, 4:3, 16:9, 9:16, 2:3, 3:2
   - 详情页竖版宽高比：3:4, 9:16, 2:3
   - 输出语言选项：中文、English、日本語
   - 分辨率选项：标清 1K / 高清 2K / 超清 4K
   - 视频时长选项：4s, 8s, 10s, 15s
   - 视频分辨率选项：720p, 1080p, 4K
   - 积分消耗常量

### 步骤 2：创建共享 UI 组件

按以下顺序创建共享组件，每个组件包含 JSX 和对应 CSS：

1. **`FileUpload.jsx`** — 虚线框上传区域
   - 支持点击/拖拽上传
   - 支持 JPG/PNG 格式过滤
   - 多图上传模式（可配置最大数量）
   - 上传后显示缩略图 + 删除按钮
   - 支持批量删除、追加上传
   - 提示文案可配置

2. **`TextAreaWithCount.jsx`** — 带字数统计的多行文本框
   - 可配置最大字数
   - 实时显示当前字数/最大字数
   - 超出字数时文字变红
   - 可配置 placeholder 和参考示例

3. **`SelectDropdown.jsx`** — 下拉选择框
   - 选项列表可配置
   - 默认值可配置
   - 统一暗色主题样式

4. **`RadioGroup.jsx`** — 单选按钮组
   - 选项列表可配置
   - 默认选中可配置
   - 横向排列，选中高亮

5. **`StepIndicator.jsx`** — 步骤引导条
   - 支持配置步骤数量和标签
   - 当前步骤高亮
   - 已完成步骤标记

6. **`GenerateButton.jsx`** — 生成操作按钮
   - 大尺寸主操作按钮
   - 支持禁用状态（置灰）
   - 支持加载动画 + 文字切换
   - 下方积分消耗提示

7. **`ImagePreviewGrid.jsx`** — 图片网格预览
   - 网格布局展示
   - 每张图片下方操作按钮（下载/重新生成/收藏/分享）
   - 支持批量下载、批量删除
   - 点击放大预览（调用 Modal）

8. **`ImageCompareView.jsx`** — 图片对比视图
   - 左右分栏对比（原图 vs 精修图）
   - 支持点击放大
   - 配套操作按钮

9. **`VideoPlayer.jsx`** — 视频播放器
   - 播放/暂停控制
   - 下载/重新生成/分享按钮

10. **`ProgressBar.jsx`** — 进度条
    - 动画进度展示
    - 百分比文字

11. **`Modal.jsx`** — 弹窗组件
    - 图片放大预览
    - 点击外部关闭

12. **`Sidebar.jsx`** — 左侧功能导航
    - 5 个导航项：主图生成、详情图生成、图片精修、视频生成、提示词画廊

## 五、关键设计决策

1. **路由方案**：使用 HashRouter，兼容 Vite 静态部署，无需服务端配置
2. **样式方案**：保持纯 CSS 文件（与现有项目一致），不引入 CSS-in-JS
3. **状态管理**：使用 React Context（已有 AIProvider），不引入 Redux
4. **组件粒度**：共享组件足够通用，页面组件包含业务逻辑
5. **文件上传**：纯前端预览，不实际上传到服务器（API 对接时替换）
6. **生成结果**：使用 mock 数据展示，API 对接时替换为真实调用
