# 🎯 UI 工作流优化方案 — 图片→视频串联 + 批量生成 + PSD 智能分层

## 一、Google Flow 核心设计理念分析

Google Flow（2026年2月改版）的核心 UI 理念：

| 特性 | 描述 | 对我们的启发 |
|------|------|-------------|
| **Asset Grid（资产网格）** | 所有生成的图片和视频以网格形式展示，可搜索/过滤/排序 | 需要一个「资产面板」统一管理所有生成结果 |
| **Collections（集合）** | 将图片和视频分组到集合中，方便项目组织 | 需要按项目/主题组织生成结果 |
| **@引用** | 在提示词中用 `@` 引用已有图片，如 "animate @hero-shot with slow zoom" | 需要支持从资产面板拖拽/引用图片到输入框 |
| **图→视频一体化** | 先用 Nano Banana 生成图片，再直接作为 Veo 的输入生成视频 | **核心需求**：图片结果一键发送到视频生成 |
| **Lasso 编辑** | 精确选择图片区域，用自然语言编辑 | 未来可扩展 |
| **批量生成** | 1个提示词最多4张同时生成 | 已有 ×1/×2/×4 参数 |

**关键洞察**：Flow 的核心不是"聊天式界面"，而是**资产驱动的创作流**。图片不是终点，而是视频的素材。

## 二、当前工作流断裂点诊断

### 2.1 图片→视频 完全断裂

```
当前状态：
  生成图片 → [下载] → 结束 ❌
  生成视频 → 需要手动上传图片 ❌
  
期望状态：
  生成图片 → [生成视频] → [PSD分层] → 下载
              ↑ 一键传递    ↑ 一键传递
```

**具体代码问题**：
- CreativeHub 用 `ImageGenerator` 而非 `VideoGenerator` 生成视频
- 视频模式下上传图片（图生视频）完全未实现
- `ImageResultCard` 没有"生成视频"按钮
- `VideoGenerator.fromImage()` 方法已存在但从未被调用

### 2.2 PSD 分层在 Hub 中不可用

- `handleSend` 没有 `psdLayer` 分支
- `ImageGenerator` 不支持 PSD 操作
- PsdLayer 独立页面与 CreativeHub 无数据共享

### 2.3 批量生成效率低

- 每次只能输入一个提示词
- 无法批量输入多个提示词并行生成
- 无法从画廊/模板快速选择提示词

## 三、UI 改造方案

### 3.1 新增「资产面板」— AssetShelf

借鉴 Google Flow 的 Asset Grid，在右侧添加可折叠的资产面板：

```
┌────────┬──────────────────────────────────┬──────────┐
│        │                                  │ 资产面板  │
│  Dock  │        对话流 / 欢迎页            │          │
│        │                                  │ [图片]   │
│  图片  │                                  │ [视频]   │
│  视频  │                                  │ [PSD]   │
│  精修  │                                  │          │
│  PSD   │                                  │ 拖拽到   │
│        │                                  │ 输入框   │
│        ├──────────────────────────────────│          │
│        │     SmartCommandBar              │          │
└────────┴──────────────────────────────────┴──────────┘
```

**功能**：
- 展示当前会话中所有生成的图片/视频缩略图
- 按类型过滤（图片/视频/PSD）
- 点击缩略图可放大预览
- **拖拽到输入框**自动设为参考图
- 每个资产有快捷操作：生成视频 / PSD分层 / 下载 / 删除

### 3.2 图片结果卡片增加工作流按钮

**ImageResultCard 新增按钮**：

```
┌─────────────────────┐
│     生成的图片        │
│                     │
│  [下载] [收藏] [重绘] │  ← 现有
│  [🎬生成视频] [📐PSD分层] │  ← 新增
└─────────────────────┘
```

- **🎬 生成视频**：点击后自动切换到视频分类，将该图片作为参考图填入
- **📐 PSD分层**：点击后自动切换到PSD分类，将该图片URL传入处理

### 3.3 批量快捷生成 — QuickBatchBar

在欢迎页和输入区上方添加批量生成入口：

```
┌──────────────────────────────────────────────────┐
│  🚀 批量生成                                      │
│  ┌──────────────────────────────────────────────┐│
│  │ 提示词1: 赛博朋克猫咪                        ││
│  │ 提示词2: 日落海滩电影感                      ││
│  │ 提示词3: 雪山木屋冬季                        ││
│  │ [+ 添加更多]                                 ││
│  └──────────────────────────────────────────────┘│
│  模型: [GPT Image 2]  比例: [1:1]  数量: [×1]    │
│  [🚀 批量生成 (3个提示词)]                        │
└──────────────────────────────────────────────────┘
```

**功能**：
- 支持输入多个提示词，每行一个
- 统一选择模型和参数
- 一键并行生成所有提示词
- 结果按提示词分组展示

### 3.4 工作流串联 — WorkflowChain

在对话流中可视化展示工作流链路：

```
┌──────────────────────────────────────────┐
│  🖼 图片生成 → 🎬 视频生成 → ✅ 完成     │
│                                          │
│  [图片缩略图] ──→ [视频缩略图]           │
│   "赛博朋克猫"    "猫咪动画5s"           │
│                                          │
│  提示词: "赛博朋克猫咪"                   │
│  模型: GPT Image 2 → Kling V1.6          │
│  耗时: 8s + 45s                          │
└──────────────────────────────────────────┘
```

## 四、PSD 智能分层升级方案

### 4.1 bggg-creator-image2psd 能力分析

该工具的核心能力：

| 功能 | 描述 | 我们的应用 |
|------|------|-----------|
| **多图组装 PSD** | 把多张图片按顺序叠成 PSD 图层 | 用户可上传多张图 → 组装成 PSD |
| **颜色聚类拆层** | 按颜色将单张图拆成多个图层 | 自动分析图片颜色 → 拆分为独立图层 |
| **去底模式** | white/white-preserve/corner/color | AI 抠图 + 背景保留选项 |
| **文字栅格层** | 添加文字作为栅格图层 | 支持在 PSD 中添加文字层 |
| **Manifest JSON** | 声明式定义图层结构 | 前端可视化编辑图层配置 |
| **全画布透明 PNG** | 每层都是全画布尺寸，Photoshop 直接叠放 | 确保图层对齐 |

### 4.2 PSD 分层在 CreativeHub 中的集成

**当前问题**：PsdLayer 是独立页面，与 CreativeHub 无数据共享。

**改造方案**：将 PSD 分层作为 CreativeHub 的一个完整工作模式，而非独立页面。

**PSD 模式的 SmartCommandBar**：

```
┌──────────────────────────────────────────────────┐
│  模式: [智能拆层] [颜色拆层] [多图组装]           │
│                                                   │
│  📎 │ 上传图片或从资产面板拖入...      │ ▶ 开始   │
│                                                   │
│  去底模式: [自动] [白底] [角采样] [指定色]         │
│  拆层数量: [3] [5] [8] [10]                       │
│  💰 预计消耗: 15 积分                              │
└──────────────────────────────────────────────────┘
```

**三种 PSD 模式**：

1. **智能拆层**（当前已有）：AI抠图 → 背景补全 → PSD打包
2. **颜色拆层**（新增，参考 bggg）：按颜色聚类拆成多个图层
3. **多图组装**（新增，参考 bggg）：多张图片按顺序叠成 PSD

### 4.3 PSD 结果展示升级

**当前**：只显示前景和背景两张预览图。

**升级后**：

```
┌──────────────────────────────────────────────┐
│  📐 PSD 分层结果                               │
│                                               │
│  图层列表:                                     │
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐                │
│  │背景│ │主体│ │文字│ │装饰│  ← 每层缩略图    │
│  └────┘ └────┘ └────┘ └────┘                │
│                                               │
│  [下载PSD] [下载全部图层PNG] [在Photoshop中打开] │
└──────────────────────────────────────────────┘
```

## 五、实施步骤

### Phase 1：修复核心工作流断裂（高优先级）

**Step 1.1**: 修复视频生成 — 用 VideoGenerator 替换 ImageGenerator
- 修改 CreativeHub.jsx 的 handleSend，视频模式使用 VideoGenerator
- 实现图生视频（fromImage）逻辑
- 实现异步任务轮询（pollUntilComplete）

**Step 1.2**: 修复 PSD 分层 — 在 CreativeHub 中实现 psdLayer 模式
- handleSend 添加 psdLayer 分支
- 调用 psdLayerGenerator.processImage
- 实现 SSE 进度监听

**Step 1.3**: ImageResultCard 增加工作流按钮
- 新增「生成视频」按钮 → 切换到视频模式 + 填入参考图
- 新增「PSD分层」按钮 → 切换到PSD模式 + 填入图片

### Phase 2：资产面板 + 工作流串联（中优先级）

**Step 2.1**: 创建 AssetShelf 组件
- 右侧可折叠面板
- 展示当前会话所有生成结果
- 按类型过滤
- 支持拖拽到输入框

**Step 2.2**: 创建 WorkflowChain 组件
- 可视化展示图片→视频的工作流链路
- 在对话流中显示关联关系

**Step 2.3**: 升级 VideoResultCard
- 增加更多操作按钮
- 显示来源图片缩略图

### Phase 3：批量生成 + PSD 增强（中优先级）

**Step 3.1**: 创建 QuickBatchBar 组件
- 多行提示词输入
- 统一参数选择
- 并行生成

**Step 3.2**: PSD 模式升级
- 新增颜色拆层模式
- 新增多图组装模式
- 结果展示升级为图层列表

**Step 3.3**: 后端集成 bggg-creator-image2psd
- 安装 Python 依赖（Pillow, numpy, opencv-python, scikit-learn）
- 创建 Express 路由调用 Python 脚本
- 实现颜色拆层 API
- 实现多图组装 API
