# UI 终极优化方案 — 图片视频一站式 AI 创作平台

## 一、核心设计理念

**一句话定位**：像 Midjourney 一样简单，像 Photoshop 一样专业。

**当前问题诊断**：
1. **导航冗余**：Topbar 6个链接 + Sidebar 6个导航 + ModelSidebar 分类，三层导航互相打架
2. **功能割裂**：图片/视频/精修/PSD分散在不同路由，用户需要来回跳转
3. **左侧边栏太宽**：280px 的 ModelSidebar 挤压了主内容区
4. **Tab 占位页空转**：详情图/精修/视频三个 Tab 显示"开发中"，浪费界面空间
5. **输入栏参数用 select 下拉**：原生 select 在深色主题下丑陋，且不够直观

**优化方向**：
- **砍掉冗余层**：Topbar 只保留品牌+用户操作，Sidebar 合并进 ModelSidebar
- **单页面一站式**：所有功能在一个页面内完成，无需路由跳转
- **输入栏智能化**：模型/参数用胶囊按钮组替代 select
- **视觉精致化**：玻璃态、微动画、品牌色渗透

### 关键变化

| 项目 | 当前 | 优化后 |
|------|------|--------|
| Topbar | 6个导航链接 | 仅品牌+用户操作（极简） |
| 左侧栏 | 280px 宽 ModelSidebar | **56px 窄轨 ModelRail**（图标+悬浮展开） |
| 模型选择 | 左侧栏内嵌列表 | **输入栏上方胶囊按钮组** |
| 功能切换 | Tab 切换（有空占位） | **ModelRail 图标切换**（自动适配输入区） |
| 参数选择 | 原生 select 下拉 | **胶囊按钮组**（1:1 / 16:9 / 9:16） |
| 主内容区 | 被侧边栏挤压 | **全屏沉浸**，最大宽度 960px 居中 |

## 三、ModelRail 窄轨侧栏设计

### 3.1 布局

```
┌──────┐
│  ✨  │  ← Logo（点击回到欢迎页）
├──────┤
│      │
│  🎨  │  ← 图片生成（选中时高亮+品牌色指示条）
│      │
│  🎬  │  ← 视频生成
│      │
│  ✏️  │  ← 图片精修
│      │
│  📦  │  ← PSD分层
│      │
│  📚  │  ← 画廊
│      │
├──────┤
│      │
│  ⚙️  │  ← 设置（底部）
│      │
└──────┘
```

### 3.2 交互

- **默认**：56px 窄轨，仅显示图标
- **Hover**：图标右侧弹出 tooltip 标签（"图片生成"）
- **选中**：图标左侧 3px 品牌色指示条 + 图标发光
- **点击图片/视频图标**：主内容区输入栏上方展开模型选择胶囊组

### 3.3 视觉

- 背景：`rgba(6,9,20,0.95)` + 右侧 1px 分隔线
- 图标：24px，默认 `#73859f`，hover `#aebcd0`，active 品牌色
- 选中指示条：3px 宽，品牌色，带 `glowPulse` 动画

## 四、输入区重构 — 智能输入栏

### 4.1 布局

```
┌──────────────────────────────────────────────────────────┐
│  模型选择胶囊组（根据当前 Rail 分类动态显示）                │
│                                                          │
│  [GPT Image 2] [DALL-E 3] [Flux Pro] [豆包] [SD XL]     │
│      ✓选中                                               │
│                                                          │
├──────────────────────────────────────────────────────────┤
│  [📎参考图缩略图]                                         │
│  ┌──────────────────────────────────────────────────┐   │
│  │  描述你想要生成的内容...                            │   │
│  └──────────────────────────────────────────────────┘   │
│  [1:1] [16:9] [9:16]  [×1] [×2] [×4]     [✨ 生成]     │
└──────────────────────────────────────────────────────────┘
```

### 4.2 模型胶囊按钮组

替代原来的 select 下拉和左侧模型列表：

```jsx
// 每个模型一个胶囊按钮
<button className={`modelCapsule ${selected ? 'active' : ''}`}>
  <ModelLogo provider={model.provider} size={20} />
  <span>{model.name}</span>
  <span className="capsulePrice">{model.pricing.perImage}积分</span>
</button>
```

- **默认态**：透明背景 + 细边框
- **选中态**：品牌色背景（15% 透明度）+ 品牌色边框 + 左侧品牌 Logo 发光
- **Hover**：微放大 + 边框变亮

### 4.3 参数胶囊按钮组

替代原来的 select 下拉：

```
尺寸：[1:1] [16:9] [9:16]     数量：[×1] [×2] [×4]
```

- 选中态：`#42e6ff` 背景（20% 透明度）+ 白色文字
- 未选中：透明 + `#73859f` 文字

### 4.4 视频模式输入区

当 ModelRail 选中"视频"时，输入区自动切换：

```
┌──────────────────────────────────────────────────────────┐
│  [Kling可灵] [Veo 3.1] [Sora 2] [Seedance] [Runway] ... │
│                                                          │
│  [📎参考图（图生视频）]                                    │
│  ┌──────────────────────────────────────────────────┐   │
│  │  描述你想要生成的视频内容...                         │   │
│  └──────────────────────────────────────────────────┘   │
│  [5秒] [10秒]  [16:9] [9:16]  [标准] [高清]   [✨ 生成]  │
└──────────────────────────────────────────────────────────┘
```

## 五、Topbar 极简化

### 5.1 当前 vs 优化后

**当前**：
```
[Logo] [主图生成] [详情图] [精修] [PSD分层] [视频] [画廊]  [积分] [EN/中] [用户]
```

**优化后**：
```
[Logo AI创作平台]                              [积分] [EN/中] [用户头像]
```

- 移除所有导航链接（功能已整合到 ModelRail）
- Topbar 变成纯品牌栏 + 用户操作栏
- 高度从 72px 缩减到 56px，给主内容区更多空间

## 七、实施步骤

### Step 1: Topbar 极简化
- 移除 Topbar 中的导航链接（主图生成/详情图/精修/PSD分层/视频/画廊）
- 仅保留：Logo + 积分 + 语言切换 + 用户头像
- 高度从 72px → 56px
- 移动端菜单同步精简

### Step 2: ModelRail 窄轨侧栏
- 新建 `ModelRail.jsx`，56px 宽图标轨道
- 5 个功能图标：图片/视频/精修/PSD/画廊
- 选中态：左侧品牌色指示条 + 图标发光
- Hover 态：右侧弹出 tooltip

### Step 3: 输入区重构 — 模型胶囊组
- 新建 `ModelCapsuleGroup.jsx`
- 替代 InputBar 中的 select 下拉
- 根据当前 ModelRail 分类动态显示对应模型
- 每个胶囊：品牌 Logo + 模型名 + 积分

### Step 4: 输入区重构 — 参数胶囊组
- 新建 `ParamCapsuleGroup.jsx`
- 尺寸：[1:1] [16:9] [9:16] 胶囊按钮
- 数量：[×1] [×2] [×4] 胶囊按钮
- 视频模式：时长 [5秒] [10秒] + 画质 [标准] [高清]

### Step 5: CreativeHub 重构
- 移除 ModelSidebar（280px）→ 替换为 ModelRail（56px）
- 移除顶部 Tab 栏（功能已整合到 ModelRail）
- 欢迎页改为 4 宫格功能卡片
- 输入区使用新的胶囊组件
- 主内容区全屏沉浸，最大宽度 960px 居中

### Step 6: 欢迎页 4 宫格卡片
- 新建 `WelcomeCard.jsx`
- 4 个功能卡片：图片生成/视频生成/图片精修/PSD分层
- 每个卡片显示：图标 + 名称 + 模型数量 + 开始创作按钮
- 底部提示词快捷标签

### Step 7: 样式升级
- ModelRail 样式（56px 窄轨 + 指示条 + tooltip）
- 模型胶囊样式（品牌色 + 选中发光）
- 参数胶囊样式（紧凑 + 直观）
- 欢迎页卡片样式（玻璃态 + 悬浮动效）
- Topbar 极简样式

### Step 8: 清理旧组件
- 移除或保留 `Sidebar.jsx`（已不使用）
- 移除 `ModelSidebar.jsx` 中的宽列表逻辑
- 清理 `App.jsx` 中不再需要的路由（详情图/精修/视频独立路由可保留但不在 Topbar 暴露）

## 九、视觉规范补充

- 圆角：16px
