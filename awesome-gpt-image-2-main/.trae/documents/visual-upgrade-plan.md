## 二、原有功能整合设计思路

### 2.1 核心原则：CreativeHub 作为统一入口

```
                    ┌─────────────────────────────┐
                    │      CreativeHub 统一入口     │
                    │   （对话式创作中心）           │
                    └──────────┬──────────────────┘
                               │
          ┌────────────────────┼────────────────────┐
          ▼                    ▼                     ▼
   ┌─────────────┐    ┌─────────────┐       ┌─────────────┐
   │ 文生图模式    │    │ 专业模式     │       │ 高级模式     │
   │ (Chat流式)   │    │ (嵌入原页面)  │       │ (独立路由)   │
   └─────────────┘    └─────────────┘       └─────────────┘
        │                   │                      │
   • 纯提示词生成        • 详情图生成             • PSD分层
   • 参考图生成          • 图片精修              • 视频生成
   • 快速出图            • 多模块规划            • 需要复杂参数
                       • 批量处理              • 专业工作流
```

### 2.2 整合策略

| 原有功能 | 整合方式 | 说明 |
|----------|---------|------|
| **MainImageGen** | ✅ 已替换为 CreativeHub | 对话式文生图完全覆盖 |
| **DetailStudio** | 🔄 内嵌为「详情图模式」 | 在 CreativeHub 中增加 tab 切换 |
| **RetouchStudio** | 🔄 内嵌为「精修模式」 | 在 CreativeHub 中增加 tab 切换 |
| **VideoGen** | 🔄 内嵌为「视频模式」 | 在 CreativeHub 中增加 tab 切换 |
| **PsdLayer** | 🔗 保留独立路由 `/psd-layer` | 流程较特殊，保留独立页 |
| **Gallery** | 🔗 保留独立路由 `/gallery` | 浏览型页面，保持独立 |

### 2.3 CreativeHub 内部 Tab 结构

```
┌──────────────────────────────────────────────────────┐
│  [💬 对话] [📦 详情图] [✏️ 精修] [🎬 视频]         │  ← 模式切换 Tab
├──────────────────────────────────────────────────────┤
│                                                      │
│   当前选中模式的专属内容区                              │
│                                                      │
│   对话模式 → ChatStream + InputBar                    │
│   详情图模式 → DetailStudio 内容（内嵌）              │
│   精修模式 → RetouchStudio 内容（内嵌）               │
│   视频模式 → VideoGen 内容（内嵌）                    │
│                                                      │
└──────────────────────────────────────────────────────┘
```
